## 修复：merchant-admin 找不到 CouponTemplateMapper Bean

- 现象：IDEA 报 "无法自动装配。找不到 'CouponTemplateMapper' 类型的 Bean"，`CouponTemplateServiceImpl` 构造器注入 final 字段失败。
- 根因：`CouponTemplateMapper` 是普通接口，无 `@Mapper`；`MerchantAdminApplication` 只有 `@SpringBootApplication`，缺 `@MapperScan`，Maven 移植时漏掉。MyBatis-Plus starter 的兜底自动扫描只收带 `@Mapper` 的接口，所以也没兜住。
- 修复：`merchant-admin/.../MerchantAdminApplication.java` 补 `@MapperScan("org.sylvester.merchant.admin.dao.mapper")`，与参考项目 `E:/work/Java/onecoupon` 的写法保持一致（该项目四个启动类均采用启动类集中扫描，Mapper 接口上不加 `@Mapper`）。
- 验证：`mvn -o -pl merchant-admin -am -DskipTests clean compile` BUILD SUCCESS。
- 后续：engine / settlement / distribution / search 目前还没有 `dao.mapper` 包；将来加 Mapper 时需在各自启动类补对应 `@MapperScan`，否则会复现同一问题。
